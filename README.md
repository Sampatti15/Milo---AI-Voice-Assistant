# Milo - AI Voice Assistant 🎙️🤖

Milo is a Python-based AI Voice Assistant inspired by intelligent virtual assistants like Jarvis.  
It is designed to perform useful daily tasks through simple voice commands in a lightweight and beginner-friendly way.

---

## ✨ Features

- 🕒 Tells current date and time
- ▶️ Plays YouTube videos/music
- 🌐 Answers questions using Wikipedia
- 💬 Responds to basic conversations
- 🎤 Supports voice commands
- 🔊 Gives voice responses using text-to-speech

---

## 🛠️ Tech Stack

- Python
- SpeechRecognition
- pyttsx3
- Wikipedia API
- PyWhatKit
- Requests

---

## 📌 How Milo Works

1. User gives a voice command through microphone
2. Milo listens and processes the speech
3. Based on the command, Milo:
   - Plays YouTube content
   - Searches information on Wikipedia
   - Tells current date and time
   - Responds to basic questions
4. Milo replies using voice output

## ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/Sampatti15/Milo---AI-Voice-Assistant
```

Go to the project folder:

```bash
cd Milo-AI-Assistant
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python Milo.py
```
